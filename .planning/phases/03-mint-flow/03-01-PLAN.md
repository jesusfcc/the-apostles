Create `contracts/src/EasterEgg.sol`:
- Inherit OpenZeppelin ERC721URIStorage + Ownable (OZ v5 pattern)
- `pragma solidity ^0.8.20`
- Constructor: `ERC721("Easter Egg", "EGG")`, `Ownable(msg.sender)`
- `uint256 private _nextTokenId` (no Counters.sol — removed in OZ v5)
- `mapping(address => bool) public hasMinted` — one egg per address
- `function mint(string calldata tokenURI) external` — checks `!hasMinted[msg.sender]`, sets true, increments `_nextTokenId`, calls `_safeMint` + `_setTokenURI`
- `function burn(uint256 tokenId) external` — requires `ownerOf(tokenId) == msg.sender`, calls internal `_update(address(0), tokenId, msg.sender)` (OZ v5 burn pattern). This enables Phase 5 burn/evolve.
- `function totalSupply() external view returns (uint256)` — returns `_nextTokenId`

Create `contracts/script/DeployEasterEgg.s.sol`:
- Standard Foundry Script pattern: reads `PRIVATE_KEY` from env, broadcasts, deploys EasterEgg, logs address
- Import forge-std/Script.sol and ../src/EasterEgg.sol

Create `contracts/test/EasterEgg.t.sol`:
- Basic test: deploy, mint with tokenURI, verify ownerOf, verify tokenURI, verify hasMinted is true
- Test: second mint from same address reverts with "Already minted"
- Test: burn by owner succeeds, burn by non-owner reverts

Run `cd contracts && forge build` to verify compilation. Run `forge test` to verify tests pass.

Create `easter-egg-mint/src/lib/pinata.ts`:
- Import `PinataSDK` from "pinata"
- Lazy-init pattern (same as supabase.ts in this project): `let _pinata: PinataSDK | null = null`
- Export `getPinata()` that creates SDK with `process.env.PINATA_JWT` and `process.env.NEXT_PUBLIC_PINATA_GATEWAY`
- Server-only — PINATA_JWT is NOT prefixed with NEXT_PUBLIC (must not leak to client)

Create `easter-egg-mint/src/lib/metadata.ts`:
- Import `EggTraits` from `~/lib/traits`
- Export `buildMetadata(fid: number, traits: EggTraits, imageURI: string)` returning OpenSea-standard JSON:
  - `name`: `"Easter Egg #${fid}"`
  - `description`: `"AI-generated Easter egg for Farcaster user ${fid}"`
  - `image`: the imageURI param (ipfs://CID format)
  - `external_url`: `process.env.NEXT_PUBLIC_APP_URL || ""`
  - `attributes`: array of `{ trait_type, value }` objects mapping all 8 EggTraits fields (Dominant Color, Secondary Color, Pattern, Texture, Mood, Style, Signature Symbol, Vibe)

Create `easter-egg-mint/src/app/api/upload-metadata/route.ts`:
- Export async `POST` handler
- Parse body: `{ imageBase64: string, traits: EggTraits, fid: number }`
- Validate required fields exist, return 400 if missing
- Step 1: `getPinata().upload.public.base64(imageBase64)` — upload egg image, get CID
- Step 2: `buildMetadata(fid, traits, "ipfs://" + imageUpload.cid)` — build metadata JSON
- Step 3: `getPinata().upload.public.json(metadata)` — upload metadata, get CID
- Return `{ tokenURI: "ipfs://" + metadataUpload.cid, imageURI: "ipfs://" + imageUpload.cid }`
- Wrap in try/catch, return 500 with error message on failure
- Set Next.js body size config if needed: `export const config = { api: { bodyParser: { sizeLimit: '4mb' } } }` — but for App Router, use `export const maxDuration` and handle via request size. For Next.js App Router, body parsing is handled automatically up to ~4MB which should be sufficient.
