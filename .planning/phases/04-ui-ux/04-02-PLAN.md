    **MintScreen.tsx** — Handle the full mint pipeline:
    - Props: `imageBase64: string`, `traits: EggTraits`, `fid: number`, `onMinted: (txHash: string) => void`, `onError: (msg: string) => void`

    - Three sequential phases on mount (auto-start):

      3. "Confirming on-chain..." — watch `isConfirming` from useMintEgg
    - Show current phase with spinner and phase text
    - Show a visual stepper/progress: three dots or lines showing which phase is active
    - When `isSuccess` from useMintEgg, call `onMinted(txHash)` and store tokenURI/imageURI in flow state
    - On any error, show error message + "Try Again" button that resets and retries
    - Store tokenURI and imageURI in parent state via `onMetadataUploaded` callback (add to props if needed)

    **SuccessScreen.tsx** — Celebration screen after successful mint:
    - Props: `imageBase64: string`, `txHash: string`, `tokenURI: string | null`, `imageURI: string | null`, `onReset: () => void`
    - Show the egg image prominently (same card style as preview but slightly larger)
    - "Your egg has been minted!" heading
    - Transaction hash display (truncated with link to basescan)
    - If imageURI exists, show "View on Arweave" link
    - Share button: opens `https://warpcast.com/~/compose?text=I+just+minted+my+AI+Easter+Egg!+🥚&embeds[]=${APP_URL}` (use encodeURIComponent, import APP_URL from constants)

    - Explorer link: `https://basescan.org/tx/${txHash}` (or sepolia.basescan.org if IS_TESTNET from config)

    - Pass appropriate props from useEggFlow state data to each screen
    - For "error" state, show error message with "Start Over" button that calls reset()
